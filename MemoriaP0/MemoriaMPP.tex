void cruzar(Individuo *padre1, Individuo *padre2, Individuo *hijo1, Individuo *hijo2, int n, int m)
{	
	/*Cruzar: para cada par de individuos selecciona un punto aleatorio a partir del que se produce
	la mezcla y los nuevos descendientes se crean intercambiando los genes de los padres entre
	si.*/
	
	//Primer paso, generar el punto de corte. Cruce en un solo punto.
	//El punto de corte no se incluye como parte de los genes izquierdos.
	//Esto soluciona el problema de que salga corte = 0 y se copie 
	//directamente el padre2 entero.
	int corte = 1 + aleatorio(m-1); 

	//Copiamos al hijo1 la primera parte de los genes del padre1
	//al hijo2 lo mismo pero con el padre2
	for (int i = 0 ; i < corte ; i ++){
		hijo1->array_int[i] = padre1->array_int[i];
		hijo2->array_int[i] = padre2->array_int[i];
	}
	//Copiamos la parte restante del padre contrario
	//Es decir, al hijo1 le copiamos la segunda parte del padre2
	for (int i = corte ; i < m ; i ++){
		hijo1->array_int[i] = padre2->array_int[i];
		hijo2->array_int[i] = padre1->array_int[i];
	}
	
	//Doble bucle para revisar que no existan genes duplicados 
	//Partimos de que los padres NO tienen repetidos asi podemos 
	//ahorrarnos parte del recorrido y solo comparar los genes de 
	// la parte del padre1 con las del otro.
	for (int i = 0 ; i < corte ; i ++){
		for(int j = corte ; j < m ; j++){
			//Verificamos duplicado
			if(hijo1->array_int[i] == hijo1->array_int[j]){
				int nuevo;
				do{
					nuevo = aleatorio(n);
				}while (find_element(hijo1->array_int, m, nuevo));
				//Seguimos buscando un numero hasta que no sea uno que ya 
				//este presente. Luego actualizamos
				hijo1->array_int[j] = nuevo;
			}
			
			if(hijo2->array_int[i] == hijo2->array_int[j]){
				int nuevo;
				do{
					nuevo = aleatorio(n);
				}while (find_element(hijo2->array_int, m, nuevo));
				hijo2->array_int[j] = nuevo;
			}
		}
	}
}
\end{lstlisting}
La mezcla siempre es igual, es la forma más fácil de hacerlo. Tal y como indica la práctica, los padres se dividen en un punto aleatorio de corte, 
una vez cortado, la parte izquierda de cada padre pasa a un hijo (padre1->hijo1), y la segunda parte del corte del padre va destinada a la segunda parte del 
hijo contrario (padre1.derecha->hijo2). Esto se hace con un bucle para cada pate del corte.

La parte compleja de esta función reside en la búsqueda de genes repetidos en un mismo individuo.
Verificar que no existan genes repetidos se consigue con la ejecución de un doble bucle anidado para recorrer al individuo 
comparando la parte izquierda con la derecha.

Para cada posición se verifica que sean iguales, en caso de verificarse entramos en el objetivo de buscar un gen no repetido para 
sustituir el gen (derecha) por uno que no se repita, para ello, mientras que encontremos el nuevo elemento en el array (se hace una búsqueda completa
para verificar posiciones ya verificadas y así el nuevo elemento no sea idéntico a ningún otro) buscamos otro aleatorio (uno entre todos los n disponibles), una vez encontrado actualizamos 
el valor en el array y continuamos con el hijo2.

	*/

		nmutar=1;
	}
	
	//Para mutar los X genes
	for(int i = 0; i<nmutar; i++){
		//posicion aleatoria a mutar

Como antes de llamar a mutar ya se ha seleccionado una proporción de individuos a mutar, nos da a entender que estos seleccionados tienen que mutar como mínimo 
una vez (mientras que m\_rate > 0) por lo que nuestro objetivo en la función mutar es mutar X genes del individuo, dado por el porcentaje de m\_rate.

Bucle simple explicado en funciones anteriores.

void fitness(const double *d, Individuo *individuo, int n, int m)
{
	// Determina la calidad del individuo calculando la suma de la distancia entre cada par de enteros
		double fitness = 0.0;
	//Doble bucle para recorrer todas las posiciones del individuo para calcular su fitness
	//Se suman todas las combinaciones de los valores del subconjunto tomando 
	//como valor su representacion en el array de distancias.
	for(int i = 0 ; i < m-1 ; i++){
		for(int j = i + 1; j < m ; j++){
			fitness += distancia_ij(d,individuo->array_int[i], individuo->array_int[j], n);
		}
	}
	individuo->fitness = fitness;
}
\end{lstlisting}

\begin{lstlisting}[style=EstiloC]

double distancia_ij(const double *d, int i, int j, int n)
{
    // Devuelve la distancia entre dos elementos i, j de la matriz 'd'
	// Formula de K
	//Agregamos este if para comprobar porque la formula solo es valida con i < j, 
	//el if garantiza que siempre se cumpla i < j, que es la condicion de validez 
	//de la formula, y que es correcto porque la distancia es simetrica
	if (i > j) { int t = i; i = j; j = t; }
	int val = (((n * n)- n)/2)-((((n-i)*(n-i))-(n-i))/2)+j-i-1;
	return d[val];
}
\end{lstlisting}

Calculamos un valor de mejora para saber si nos hemos quedado estancados, si en las próximas X generaciones 
el fintess no llega a superar ese factor de mejora esperado, entonces el algoritmo converge. 

Es decir, lo que estamos haciendo es que, dada una posición inicial 0, si avanzamos 5 generaciones, y ninguna de estas supera a la esperada, entonces 
poco a poco restamos la posibiblidad de avanzar y emepzamos a converger, por el contrario si una posición logra superar ese factor de mejora, se actualizan los valores, se 
vuelve a calcular una proxima mejora y el contador de X generaciones vuelve a 0 dejándonos la posibilidad de seguir avanzando porque esto indica que el puede seguir encontrando buenas soluciones.
